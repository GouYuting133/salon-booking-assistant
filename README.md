# salon-booking-assistant
面向美发门店的 AI 预约助手，支持顾客自助预约和店主手机排班

## 项目背景

这是一个结合真实美发门店需求开发的个人项目。首版聚焦两个场景：顾客自助预约，店主用手机查看和管理日程。目前已部署在线试用版。

## 我负责的工作

- 与店主沟通预约和排班需求，确定首版功能，设计并实现顾客端和商家端流程。
- 划分 AI 与店主的职责。AI 负责查询档期、介绍项目和解答护理问题，造型判断与售后由店主处理。

## 试用迭代

顾客提交染发或烫发预约申请时需要填写手机号。店主可以在手机上看到新预约提示，从预约详情直接拨打电话，沟通后再确认预约。

## 护理知识问答迭代（本机验证）

将店主提供的 13 条染烫护理说明整理为知识库，按问题检索相关条目，再交给大模型生成回答并标注来源。

已验证洗护用品选择、多轮品牌追问、烫后吹发及资料缺失等场景。测试中发现话题误关联会导致错误回答，调整上下文继承和检索规则后，资料未覆盖的问题会引导顾客联系店主。

当前采用关键词与同义词匹配，尚未使用向量检索。本次迭代已完成本机测试，并部署到线上；已验证资料未覆盖的问题会引导顾客联系店主。
